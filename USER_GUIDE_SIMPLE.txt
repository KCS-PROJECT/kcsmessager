====================================================
   KCS Messenger v1.0 - 사용자 가이드
====================================================

[다운로드 받은 후 처음 실행하기]

1단계: 압축 해제
   - 다운로드 받은 ZIP 파일을 원하는 폴더에 압축 해제
   - 예: C:\Program Files\KCS_Messenger\

2단계: 실행
   방법 1: KCS_Messenger.exe 더블클릭
   방법 2: "실행하기.bat" 더블클릭

3단계: Windows 보안 경고 (처음만)
   "Windows의 PC 보호" 창이 나타나면
   → "추가 정보" 클릭
   → "실행" 버튼 클릭

   이 경고는 서명되지 않은 프로그램에 대한
   일반적인 경고입니다. 프로그램은 안전합니다.

====================================================

[프로그램 사용 방법]

실행하면 런처 창이 열립니다:

┌─────────────────────────────────────┐
│  KakaoTalk 실시간 채팅 런처         │
├─────────────────────────────────────┤
│                                     │
│  [서버 시작]  [서버 중지]           │
│                                     │
│  [클라이언트 추가]                  │
│                                     │
│  [독립 실행 모드]                   │
│                                     │
└─────────────────────────────────────┘

옵션 1: 실시간 채팅 (여러 명이 채팅)
   1. "서버 시작" 버튼 클릭
   2. "클라이언트 추가" 버튼 클릭
   3. 사용자 이름 입력
   4. 채팅 창이 열림
   5. 여러 클라이언트를 추가하여 대화 가능

옵션 2: 독립 실행 모드 (혼자 테스트)
   1. "독립 실행 모드" 버튼 클릭
   2. 채팅 UI 테스트

[자주 묻는 질문]

Q: 프로그램이 실행되지 않아요
A: Visual C++ 재배포 가능 패키지를 설치하세요
   다운로드: https://aka.ms/vs/17/release/vc_redist.x64.exe

Q: 한글이 깨져 보여요
A: Windows 지역 설정 확인
   설정 > 시간 및 언어 > 언어 > 한국어

Q: 실시간 채팅이 연결 안 돼요
A: 방화벽 설정 확인
   포트 5555가 차단되어 있을 수 있습니다

Q: 여러 PC에서 채팅하고 싶어요
A: 1. 한 PC에서 서버 시작
   2. 다른 PC에서 클라이언트 실행
   3. 서버 PC의 IP 주소 입력
      (예: 192.168.0.100)
