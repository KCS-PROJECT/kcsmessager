====================================================
   KCS Messenger - 파일 정리
====================================================

[Windows 사용자가 다운로드할 파일]

배포 파일:
  dist/KCS_Messenger.exe          - 실행 파일 (40-50MB)
  또는
  KCS_Messenger_v1.0.zip          - 배포 패키지 (압축)

포함 내용:
  ✓ KCS_Messenger.exe
  ✓ 실행하기.bat
  ✓ README.txt

====================================================

[개발자용 - 빌드 및 배포 도구]

빌드 스크립트:
  build_windows.bat               - Windows 자동 빌드
  build_windows.py                - Windows 빌드 Python 스크립트
  QUICK_START_WINDOWS.bat         - 원클릭 빌드+실행

배포 스크립트:
  prepare_distribution.bat        - ZIP 배포 패키지 생성
  create_installer.bat            - NSIS 설치 프로그램 생성

실행 스크립트:
  run_messenger.bat               - exe 실행

설정 파일:
  kakaotalk_launcher_windows.spec - Windows PyInstaller 설정
  kakaotalk_launcher.spec         - macOS PyInstaller 설정
  requirements_windows.txt        - Windows 필수 패키지
  requirements.txt                - 전체 패키지 목록

  dist/KCS_Messenger.exe          - Windows 실행 파일

  KCS_Messenger_Setup.exe         - 설치 프로그램 (NSIS)

====================================================

[사용 흐름]

1. 개발자 작업 (Windows PC):
   build_windows.bat
   → dist/KCS_Messenger.exe 생성
   
   prepare_distribution.bat
   → KCS_Messenger_v1.0.zip 생성
   
   GitHub/Google Drive 업로드
   → 다운로드 링크 공유

2. 사용자 작업:
   ZIP 다운로드
   → 압축 해제
   → KCS_Messenger.exe 실행
   → 완료!
