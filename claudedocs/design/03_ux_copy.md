# UX Copy: KCS Talk 오류 · 빈 화면 · 확인 창 · 토스트
스킬: `design:ux-copy` (Image #6 적용 4/8) · 날짜 2026-10-09

**문체 기준 (이번에 정리)**: 사내 메신저 → 존댓말 '-습니다/-세요'. 오류는 *무슨 일 + 이유 + 할 일* 순서. 버튼과 결과 토스트는 같은 동사(대화 내보내기 → "대화 N개를 내보냈습니다"). 사람을 가리키는 말은 카카오톡 용어 **'대화상대'**로 통일(서버 문구의 '멤버' 제거).

### 가장 큰 문제: 확인 창 버튼이 영어
`QMessageBox.question` 9곳(채팅방 나가기, 일정 삭제, 폴더 삭제, 차단, 문서 삭제, 펑 삭제 …)이 **"Yes / No"** 로 보였다.
→ 앱 시작 시 Qt 한국어 번역(`qtbase_ko.qm`)을 설치(`client/kakao/app.py: install_korean_qt_translation`) — 모든 표준 대화상자가 **"예 / 아니요"**, 파일 저장 창도 한국어. 배포본(PyInstaller `_MEIPASS`) 경로도 찾는다.

### Alternatives (통화 중 오류)
| Option | Copy | Tone | Best For |
|---|---|---|---|
| A ✅ | 이 채팅방에서 이미 통화 중입니다. 채팅방의 통화 카드에서 참여하기를 누르세요. | 안내형 | 기본 |
| B | 진행 중인 통화가 있어요. 참여하기로 들어가 보세요. | 친근 | 사내 캐주얼 톤으로 바꿀 때 |
| C | 통화 중 — 통화 카드 › 참여하기 | 압축 | 토스트 폭이 매우 좁을 때 |

### Rationale
오류 대부분이 *무엇이 안 되는지*만 말하고 *다음에 할 일*이 없었다. 사용자는 메신저 화면에서 바로 다음 행동을 해야 하므로 버튼 이름(참여하기, 나에게서 삭제)을 그대로 문구에 넣어 찾아가게 했다.

### Localization Notes
- 화살표(→)는 메뉴 경로 표기로만 쓴다. 숫자 상한(10명·30종·5분)은 서버 상수에서 만들어 바뀌어도 문구가 맞다.
- 형식 검증용 문구(`option_indexes 값이 올바르지 않습니다` 등)는 클라이언트가 먼저 막아 사용자에게 보이지 않으므로 그대로 둔다.
