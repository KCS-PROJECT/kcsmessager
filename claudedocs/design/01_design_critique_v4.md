# Design Critique: KCS Talk v4 (채팅방 새 카드 · 대화 요약 · 공감 선택 · '통화' 폴더)

- 대상: `client/kakao/chat_room.py` (ContactCard, VoiceCard, SummaryDialog, ReactionPicker, 요약 칩), `client/kakao/voice.py` (VoiceRecordDialog), `client/kakao/chats_tab.py` (CallLogRow)
- 단계: 기능 구현 직후 다듬기 (final polish 직전)
- 근거: 오프스크린 스크린샷 5장(라이트) + 토큰 대비 계산(라이트/다크)
- 스킬: `design:design-critique` (Image #6 적용 1/8)

### Overall Impression
새 요소들이 기존 카드 언어(흰 카드 · 12px 모서리 · 네이비 주요 버튼)를 잘 따라 처음 봐도 같은 앱으로 읽힌다. 가장 큰 기회는 **음성 파형·재생 버튼이 글자 기호(▶, ❚❚)와 옅은 막대에 기대고 있다는 점**과 **다크 모드 대비**다.

### Usability
| Finding | Severity | Recommendation |
|---|---|---|
| 보이스룸 통화 기록 부제가 "보이스룸 · 보이스룸 · 3명 참여"로 모드가 두 번 나온다 | 🟡 Moderate | 보이스룸은 "보이스룸 · 3명 참여 · 20:00"처럼 모드 1회 + 참여 인원 + 길이 |
| 연락처 카드에 소속이 없으면 부제가 이름을 다시 보여 준다 (박민수 / 박민수) | 🟡 Moderate | 소속 없으면 상태메시지, 그것도 없으면 "KCS Talk 사용자" |
| 공감 선택 창에서 공감 수가 툴팁으로만 보인다 (이전에는 버튼에 숫자) | 🟢 Minor | 버튼 오른쪽 아래에 작은 숫자 배지로 그리기 |
| 대화 요약 결과에 "다시 요약"이 없어 범위(안 읽은 대화 ↔ 최근 대화)를 바꿀 수 없다 | 🟢 Minor | 창 안에 '최근 대화 전체 요약' 버튼 |
| 녹음 창이 열리자마자 녹음을 시작하는데, 마이크가 없을 때 안내만 뜨고 버튼은 '■ 정지'로 남는다 | 🟡 Moderate | 오류가 나면 버튼을 '● 녹음'으로 되돌리고 녹음 상태 해제 |

### Visual Hierarchy
- **What draws the eye first**: 내 음성 말풍선(네이비)과 연락처 카드의 '1:1 채팅' 버튼 — 맞다. 받은 연락처의 주된 행동은 대화 시작.
- **Reading flow**: 이름 → 카드 캡션 '연락처' → 프로필 → 버튼. 캡션이 프로필보다 위에 있어 종류를 먼저 알려 주는 흐름이 좋다.
- **Emphasis**: '통화' 폴더에서 부재중 행이 빨간 아이콘 + 빨간 제목으로 두 번 강조된다. 아이콘만 빨강이고 제목은 기본색 + 부제에 '부재중'을 굵게 하면 소란스럽지 않다 (카카오톡도 부재중은 아이콘·부제로 표시).

### Consistency
| Element | Issue | Recommendation |
|---|---|---|
| 아이콘 | 재생/정지가 글자 기호 ▶ ❚❚ (craft floor: 기호·이모지를 아이콘으로 쓰지 않음) | QPainter로 그린 재생 삼각형/정지 막대 아이콘 |
| 요약 칩 | 사각에 가까운 모서리, 다른 칩(폴더 칩 15px 둥근)과 다름 | 같은 radius·높이·글자 크기 |
| 버튼 이름 | 연락처 카드 '프로필' vs 프로필 창의 '프로필 보기' | '프로필 보기'로 통일 |
| 녹음 창 | 제목 라벨만 있고 다른 대화상자처럼 dialog_qss 제목 스타일이 아님 | 다른 대화상자와 같은 제목 크기 |

### Accessibility
- **Color contrast** (WCAG, 계산값):
  - 파형 미재생 막대 2.24~2.57:1 → ❌ 비텍스트 3:1 미달 → 알파 90 → 150
  - 다크 모드 받은 음성 재생 진행색(accent) 2.57:1 → ❌ → 다크에서는 `text` 색으로
  - 다크 모드 `cardHint` 3.88:1, 부재중 제목(badge) 3.45:1 → ❌ 4.5:1 미달 → 다크용 토큰 보정
  - 음성 길이·카드 부제·요약 칩 4.5:1 이상 ✅
- **Touch targets**: 재생 버튼 32px, 공감 선택 46×38 ✅ / 공감 '+N' 칩 높이 약 22px — 데스크톱 마우스 기준 허용, 키보드 포커스는 가능
- **Text readability**: 요약 본문 13px · 줄간격 기본 — 길어지면 빽빽함. 줄 간격 1.5

### What Works Well
- 연락처 카드: 캡션 → 프로필 → 두 버튼의 3단 구조가 기존 일정·투표 카드와 같은 문법이다.
- '통화' 폴더: 모드 아이콘·방 이름·방향·길이·시각이 한 줄에 정리되어 카카오톡 통화 목록과 같은 정보량.
- 공감이 넘칠 때 +N으로 접고 말풍선 폭 안에 머무르게 해, 레이아웃이 깨지지 않는다.

### Priority Recommendations
1. **음성 말풍선 아이콘·파형 대비** — 글자 기호 대신 그린 아이콘, 미재생 막대 알파 상향, 다크 진행색 보정 (지금은 3:1 미달이라 막대가 거의 안 보이는 화면이 있다).
2. **통화 기록 문구·강조 정리** — 보이스룸 중복 제거, 부재중은 아이콘·부제로만 강조.
3. **다크 모드 토큰 보정** — `text_hint`(카드 안내), `badge`(부재중) 다크 값을 4.5:1 이상으로.
