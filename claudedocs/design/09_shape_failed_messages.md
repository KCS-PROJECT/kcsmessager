# Shape brief: 보내지 못한 메시지 (전송 실패 · 재전송 · 삭제)
Image #7 순서 1단계 `shape` — 발견 질문 1회 진행 후 확정 (2026-10-09). 다음 단계: craft → animate → polish → audit → adapt.

**발견 질문 답변 (사용자 확정)**
- 처리 방식: **카카오톡처럼** — 빨간 ! + '재전송 / 삭제', 다시 연결돼도 자동으로 보내지 않고 사용자가 고른다.
- 보존 범위: **앱을 꺼도 유지** — 이 PC 설정에 저장, 다시 켜도 채팅방에 남는다.

1. **Job and audience:** 이동·회의 중 노트북 Wi-Fi가 끊긴 상태에서 답장을 쓴 임직원. 지금은 메시지가 **아무 표시 없이 사라져** 보냈다고 믿는다 (업무 사고 위험). 모드: Operate.
2. **Outcome and proof:** 보내지 못한 메시지를 바로 알아보고(빨간 ! · '전송 실패'), 연결이 돌아오면 한 번에 재전송하거나 지운다. 성공 = 사라지는 메시지 0개.
3. **Direction:** 기존 KCS Talk 말풍선 세계 그대로. 실패 말풍선은 내 말풍선 색을 유지하되 옆 시간 자리에 그린 빨간 ! 버튼(원 + 느낌표, 기호 글자 아님)과 `danger_text` '전송 실패'. 누르면 '재전송 / 삭제' 메뉴. 채팅 목록 행 미리보기에도 '보내지 못한 메시지' 표시.
4. **Scope:** 텍스트·이모티콘 (파일·사진은 용량 때문에 보존하지 않고 즉시 "연결이 끊겨 파일을 보내지 못했습니다" 안내). 서버 프로토콜 변경 없음 (클라이언트만). 비밀채팅은 암호문을 보존하지 않고 같은 안내.
5. **States:** 정상 → 실패(연결 없음) → 재전송 시 연결 있으면 정상 전송·실패 말풍선 제거 / 아직 없으면 그대로 + 토스트. 삭제 → 확인 없이 제거(내 PC에만 있던 글). 여러 개 실패 시 순서 유지, 항상 대화 맨 아래.
6. **Interaction:** 마우스: ! 클릭 또는 말풍선 우클릭 → 재전송/삭제. 키보드: Alt+↑로 선택 → Shift+F10. 스크린리더: "보내지 못한 메시지: 내용".
7. **Constraints:** 실패 메시지는 읽음 처리·안 읽은 수 계산에서 제외(서버 msg_id 가 아님). 로컬 id 는 서버 id 보다 항상 큰 범위(10^12+). 설정 키 `failed_messages`.
