# KCS Messenger 다운로드 및 실행 가이드

## 🎯 Windows 사용자를 위한 간단 가이드

### 방법 1: GitHub에서 다운로드 (권장)

#### 단계별 설명

1. **다운로드 페이지 방문**
   ```
   https://github.com/사용자명/kcsmessager/releases
   ```

2. **최신 버전 찾기**
   - "Latest" 태그가 있는 릴리스 클릭
   - 또는 "v1.0" 등 원하는 버전 선택

3. **파일 다운로드**
   - "Assets" 섹션 확장
   - `KCS_Messenger_v1.0.zip` 클릭하여 다운로드

4. **압축 해제**
   - 다운로드한 ZIP 파일 우클릭
   - "압축 풀기" 또는 "Extract All" 선택
   - 원하는 폴더 선택 (예: `C:\Program Files\KCS_Messenger\`)

5. **실행**
   - 압축 푼 폴더 열기
   - `KCS_Messenger.exe` 더블클릭
   - 또는 `실행하기.bat` 더블클릭

6. **Windows 보안 경고** (처음만)
   - "Windows의 PC 보호" 창이 나타나면
   - "추가 정보" 클릭
   - "실행" 버튼 클릭
   - ✅ 프로그램은 안전합니다!

### 방법 2: 직접 다운로드 링크

개발자가 제공하는 직접 링크:

```
https://github.com/사용자명/kcsmessager/releases/download/v1.0/KCS_Messenger_v1.0.zip
```

브라우저 주소창에 위 링크를 붙여넣고 Enter → 자동 다운로드

### 방법 3: Google Drive (대안)

Google Drive 링크가 제공된 경우:
1. 제공된 링크 클릭
2. "다운로드" 버튼 클릭
3. 압축 해제 후 실행

## 🚀 실행 방법

### 방법 A: exe 직접 실행
1. `KCS_Messenger.exe` 더블클릭
2. 런처 창이 열립니다

### 방법 B: 배치 파일 실행
1. `실행하기.bat` 더블클릭
2. 자동으로 프로그램 실행

### 방법 C: 바로가기 만들기 (편리함)
1. `KCS_Messenger.exe` 우클릭
2. "바로가기 만들기" 선택
3. 바로가기를 바탕화면으로 이동
4. 다음부터 바탕화면 아이콘 더블클릭

---

## 💬 프로그램 사용법

### 실시간 채팅 시작하기

1. **서버 시작**
   - 런처 창에서 "서버 시작" 클릭

2. **클라이언트 추가**
   - "클라이언트 추가" 버튼 클릭
   - 사용자 이름 입력
   - 채팅 창이 열립니다

3. **여러 사용자 추가**
   - "클라이언트 추가"를 여러 번 클릭
   - 각각 다른 이름 입력
   - 여러 채팅 창에서 대화 가능!

### 독립 실행 모드 (테스트용)

1. "독립 실행 모드" 버튼 클릭
2. 채팅 UI만 열림
3. 서버 없이 UI 체험 가능

## 🔧 문제 해결

### 프로그램이 실행되지 않아요

**해결 방법:**
1. Visual C++ 재배포 가능 패키지 설치
   ```
   https://aka.ms/vs/17/release/vc_redist.x64.exe
   ```
2. 다운로드 후 설치
3. 컴퓨터 재시작
4. 프로그램 다시 실행

### Windows Defender가 계속 경고해요

**이유:**
- 서명되지 않은 프로그램에 대한 일반 경고
- 프로그램은 안전합니다 (악성코드 없음)

**해결:**
1. "추가 정보" 클릭
2. "실행" 클릭
3. 또는 Windows Defender 예외 추가:
   - 설정 → Windows 보안 → 바이러스 및 위협 방지
   - 예외 관리 → 예외 추가
   - 폴더 선택 → KCS_Messenger 폴더 추가

### 한글이 깨져 보여요

**해결:**
1. Windows 설정 → 시간 및 언어
2. 언어 → 기본 설정 언어
3. 한국어 확인/추가

### 다른 PC와 채팅하고 싶어요

**방법:**
1. 한 PC에서 서버 시작
2. 다른 PC에서 KCS Messenger 실행
3. 클라이언트 추가 시 서버 IP 입력
4. 예: `192.168.0.100:5555`

**서버 IP 확인:**
```
cmd 열기 → ipconfig 입력 → IPv4 주소 확인
```
