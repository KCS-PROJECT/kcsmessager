# 🚀 KakaoTalk 실시간 채팅 시스템

## 📝 개요

시뮬레이션이 아닌 **실제 실시간 채팅**이 가능한 시스템입니다.
두 개 이상의 창을 열어서 서로 대화할 수 있습니다!

## 🎯 주요 기능

### 실시간 기능
- ✅ **실제 서버-클라이언트 통신**
- ✅ **다중 사용자 동시 접속**
- ✅ **실시간 메시지 브로드캐스팅**
- ✅ **사용자별 고유 이름**
- ✅ **입장/퇴장 알림**
- ✅ **말풍선 꼬리 디자인**

## 📂 시스템 구성

```
실시간 채팅 시스템
├── simple_chat_server.py      # 채팅 서버 (메시지 라우팅)
├── kakaotalk_real_chat.py    # 채팅 클라이언트 (UI + 네트워킹)
├── launch_real_chat.py       # GUI 런처 (쉬운 관리)
└── start_real_chat.bat       # 배치 파일 (Windows)
```

## 🚀 실행 방법

### 방법 1: GUI 런처 사용 (가장 쉬운 방법) ⭐

```bash
python launch_real_chat.py
```

또는 배치 파일 실행:
```bash
start_real_chat.bat → 1번 선택
```

#### 런처 기능:
- 🟢 **서버 시작/중지** - 버튼 클릭으로 서버 관리
- 💬 **채팅창 열기** - 원하는 만큼 창 열기
- 🚀 **빠른 시작** - 서버 + 2개 창 한번에 실행

### 방법 2: 수동 실행

#### 1단계: 서버 시작
```bash
python simple_chat_server.py
```

#### 2단계: 클라이언트 실행 (여러 개)
```bash
# 첫 번째 창
python kakaotalk_real_chat.py

# 두 번째 창 (새 터미널에서)
python kakaotalk_real_chat.py
```

### 방법 3: 배치 파일로 자동 실행

```bash
start_real_chat.bat → 4번 선택
```
서버와 2개 클라이언트가 자동으로 시작됩니다.

## 💬 사용 방법

### 1. 로그인
- 각 창에서 **다른 이름**으로 로그인
- 빠른 선택: 김철수, 이영희, 박민수
- 또는 원하는 이름 직접 입력

### 2. 대화하기
- 메시지 입력 후 Enter 또는 전송 버튼
- 실시간으로 다른 창에 메시지 표시
- 말풍선 색상:
  - 노란색: 내가 보낸 메시지
  - 흰색: 받은 메시지

### 3. 상태 확인
- 상단 상태: ● 온라인/오프라인
- 참여자 수 실시간 표시
- 입장/퇴장 시스템 메시지

## 🎨 UI 특징

### 디자인 요소
- **말풍선 꼬리**: 실제 카카오톡처럼 삼각형 꼬리
- **프로필 이미지**: 사용자별 고유 색상
- **한국어 시간**: 오전/오후 형식
- **시스템 메시지**: 입장/퇴장 알림

## 🔧 기술 구현

### 서버 (simple_chat_server.py)
```python
- Socket 기반 TCP 서버
- 멀티스레딩으로 다중 클라이언트 처리
- JSON 메시지 프로토콜
- 브로드캐스트 메시징
```

### 클라이언트 (kakaotalk_real_chat.py)
```python
- PyQt5 UI
- Socket 클라이언트
- 비동기 메시지 수신 (별도 스레드)
- 실시간 UI 업데이트 (Qt Signal/Slot)
```

### 메시지 프로토콜
```json
{
  "type": "message|join|leave|users_list",
  "content": "메시지 내용",
  "sender": "사용자명",
  "timestamp": "ISO 형식 시간"
}
```

## 📝 시나리오 예제

### 2인 대화
1. 런처 실행 → "빠른 시작" 클릭
2. 첫 번째 창: "김철수"로 로그인
3. 두 번째 창: "이영희"로 로그인
4. 서로 메시지 주고받기

### 그룹 채팅
1. 서버 시작
2. 3개 이상 클라이언트 실행
3. 각각 다른 이름으로 로그인
4. 모든 참여자가 메시지 실시간 수신

## ⚠️ 주의사항

1. **서버 먼저 시작**: 클라이언트 연결 전 서버가 실행 중이어야 함
2. **포트 충돌**: 5555 포트가 사용 중이면 서버 시작 실패
3. **방화벽**: Windows 방화벽 허용 필요할 수 있음
4. **동일 네트워크**: 현재 로컬(127.0.0.1)만 지원

## 🐛 문제 해결

### 서버 연결 실패
- 서버가 실행 중인지 확인
- 포트 5555가 사용 가능한지 확인
- 방화벽 설정 확인

### 메시지가 안 보임
- 인터넷 연결 확인
- 서버 콘솔에서 오류 메시지 확인
- 클라이언트 재시작

### 한글 깨짐
- UTF-8 인코딩 확인
- 시스템 로케일 설정 확인
