# KCS Talk 2.0 사용 가이드

카카오톡 PC 버전의 대화·일정 기능을 구현한 사내 메신저입니다.
설계/프로토콜 명세: `claudedocs/KAKAO_FEATURE_SPEC.md`

카카오톡 2024~2026 기능 조사와 반영 현황: `claudedocs/KAKAO_2025_RESEARCH.md`

## 직접 확인하는 방법 (3가지)

```bash
python3 scripts/demo.py                    # ① 시연: 서버 + 데모 데이터 + 클라이언트 2개가 바로 뜸 (Ctrl+C로 종료)
python3 scripts/demo.py --clients 3        #    클라이언트 3개 / --users 이름1,이름2 로 사용자 지정
python3 scripts/demo.py --headless-check   # ② 화면 없이 26개 핵심 기능을 실제 서버로 점검해 ✓/✗ 표 출력
python3 scripts/verify_features.py         # ③ 전체 테스트(401개)를 기능 69개별 PASS/FAIL 표로 → claudedocs/FEATURE_VERIFICATION.md
```
앱 안에서는 **더보기 → 기능 둘러보기**: 기능 72개 목록, [해보기] 버튼으로 해당 화면 바로 열기, 체크 표시, '검증 결과' 탭.

## v3 기능 (카카오톡 조사 결과 전부 반영)
| 기능 | 사용법 |
|---|---|
| 비밀채팅 | 친구 우클릭 → 비밀채팅. X25519+AES-GCM 종단간 암호화, 키는 이 PC에만(`~/.kcs_messenger/keys`), 서버엔 암호문만 |
| 보이스톡 · 페이스톡 · 보이스룸 | 채팅방 헤더 📞 → 보이스톡 / 페이스톡(최대 10명, 화면 공유, 배경 흐림) / 보이스룸(진행자·스피커·리스너, 손들기, 48시간 자동 종료). 보이스톡 녹음·자동 녹음(더보기) |
| 펑 | 친구 탭 맨 위 '펑' 줄 → + 로 24시간 스토리 올리기, 친구 펑 보기, 내 펑은 본 사람 목록 |
| 멀티프로필 | 더보기 → 멀티프로필: 친구마다 다른 이름·상태메시지·사진 |
| 친구 숨김 · 차단 | 친구 우클릭 → 숨기기/차단, 더보기 → 친구 관리에서 해제 (차단하면 상대 메시지가 오지 않음, 상대는 모름) |
| 잠금모드 | 더보기 → 잠금모드: 4자리 PIN, N분 무입력 시 회사 로고 잠금 화면, 잠금 중 알림 내용 숨김 |
| 키워드 알림 | 더보기 → 키워드 알림: 알림 끈 방이어도 키워드가 들어오면 알림 + 말풍선 강조 |
| 채팅방별 알림 | 채팅방 메뉴 → 알림 설정: 모든 메시지 / 멘션만 / 끄기 |
| 말풍선 꾸미기 | 더보기 → 말풍선 꾸미기: 7가지 스타일 |
| 사다리 게임 | 채팅방 입력창 도구 🪜 → 참가자·결과 입력, 모두 같은 사다리·결과 |
| 톡게시판 | 채팅방 도구/메뉴 → 게시판: 글·댓글 |
| 오픈채팅 | 채팅 탭 # 버튼 → 찾기(검색·닉네임으로 참여) / 만들기 |
| 톡서랍 | 채팅 탭 서랍 버튼 → 모든 채팅방의 사진·파일·링크 |
| 받은 파일 보관 기간 | 기본 90일(`--retention-days`), 파일 카드에 보관 기한 표시, 지나면 만료 |
| 번역 | 사용자 요청으로 제외 |

참고: 페이스톡 카메라는 macOS 설정 → 개인정보 보호 및 보안 → 카메라에서 터미널(또는 Python) 허용이 필요합니다.

### 친구 추가 (전화번호 · 이메일)
- 친구 탭 오른쪽 위 👤+ 버튼 → [전화번호] 또는 [이메일] 선택 → 입력 → 친구 추가
- 상대가 프로필 편집에 등록한 휴대폰 번호/이메일과 **정확히 일치**할 때만 찾습니다(일부만 입력해 목록을 훑을 수 없음). 번호는 하이픈·공백·+82 표기를 가리지 않고, 이메일은 대소문자를 가리지 않습니다.
- 추가한 친구는 '내가 추가한 친구'에 모이고, 우클릭 → 친구 삭제. 프로필 창의 [친구 추가]로 바로 등록할 수도 있습니다.
- 다른 사람이 나를 찾게 하려면: 내 프로필 → 편집 → 전화번호·이메일 입력

### 대화상대 초대
- 그룹 채팅방: 상단 👤+ 버튼 또는 메뉴 → 대화상대 초대 → 같은 방에 추가
- 1:1 채팅방에서 초대하면 기존 대화상대 + 초대한 사람으로 **새 그룹 채팅방**이 만들어집니다
- 친구/조직도 우클릭 → "채팅방에 초대…", 채팅 목록 우클릭 → "대화상대 초대…"

### AI 비서(RAG) 설정
- 검색: 질문자가 속한 방의 대화 + 본인이 올린 문서만 검색합니다(권한 필터).
- 답변 생성: `anthropic` 패키지와 API 자격 증명(`ANTHROPIC_API_KEY` 등)이 있으면 Claude(`claude-opus-5-5`)가 답변하고,
  없으면 검색 결과를 출처와 함께 보여주는 추출형으로 동작합니다.
- 환경 변수: `KCS_RAG_MODEL`(모델 변경), `KCS_RAG_LLM=off`(Claude 사용 안 함)

### 회사 조직도 가져오기 (지주사 → 계열사 → 부서 → 구성원)
```bash
python3 scripts/import_org_xlsx.py "~/Downloads/연락처 및 조직도(20260901).xlsx"   # → server_data/org.json
python3 server/chat/chat_server.py                                                  # 재시작하면 반영
```
- 엑셀 '사내전화번호' 시트의 부서 블록(직급·이름·계정·내선·휴대폰)과 겸직(`(*)`)을 읽습니다.
- 기본 구성(`--layout groupware`)은 사내 그룹웨어 조직도와 같습니다: **케이씨에스 › 주식회사케이씨에스 › 김광묵 대표이사 · KCS관리자 + 관리팀 · 마케팅팀 · 신사업팀 · MICE사업팀 · 영업1부 · 영업2부 · 영업3부 · 기술연구소1실 · 2실 · 3실** (부서는 접힌 채 시작, 👤N › 칩을 누르면 구성원 목록). 팀(예: 2팀(SI))은 프로필에 표시됩니다. 그룹웨어 화면과 숫자가 같도록 엑셀(2026-09-01)과 다른 소속 3건을 보정합니다(`GROUPWARE_OVERRIDES`: 류병두→관리팀, 엄태식→신사업팀, 윤성목 2실 겸직 제외). 회사 인원은 그룹웨어처럼 부서 소속 인원(52명)으로 셉니다. 엑셀 그대로의 부 › 본부 › 팀 3단계가 필요하면 `--layout raw`.
- 그룹 구조는 회사 홈페이지(kcins.co.kr › 계열사) 기준: **한국지주(지주회사) → 한국컴퓨터 · 한네트 · 로지시스 · 케이씨티 · 케이씨에스**.
  계열사를 바꾸거나 더할 때: `--affiliates "한국컴퓨터,한네트,로지시스,케이씨티,케이씨에스,새계열사"`
- `server_data/org.json` 에는 개인 연락처가 들어가므로 git 에 올라가지 않습니다(.gitignore).
- 실제 조직도를 쓰면 예전 데모 사용자(홍길동 등)는 '게스트'로 표시됩니다. 사원은 자기 이름으로 로그인합니다(로그인 화면은 최근 로그인 이름을 기억).
- 조직도는 왼쪽 메뉴 '조직도' 탭에 있고, 창을 넓히면(860px 이상) 왼쪽에 항상 펼쳐집니다. 프로필에서 내선·휴대폰·계정·겸직을 볼 수 있습니다.
