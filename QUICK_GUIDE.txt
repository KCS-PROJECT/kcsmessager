  ☐ prepare_distribution.bat 실행
  ☐ ZIP 파일 확인
  ☐ README.txt 포함 확인

업로드:
  ☐ GitHub Release 생성
  ☐ ZIP 파일 업로드
  ☐ 다운로드 링크 테스트

╔══════════════════════════════════════════════════════╗
║   문제 해결                                          ║
╚══════════════════════════════════════════════════════╝

Python 없음:
  → https://python.org 에서 설치
  → "Add Python to PATH" 체크!

빌드 실패:
  → build_windows.bat --clean --fresh

실행 안됨:
  → Visual C++ 설치
  → https://aka.ms/vs/17/release/vc_redist.x64.exe

Windows Defender:
  → "추가 정보" → "실행"
